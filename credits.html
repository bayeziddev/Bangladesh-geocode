Project / Provenance

Credits & License

This project packages Bangladesh administrative reference data in formats that are practical for developers, analysts, and GIS users.

Maintainers and sources

Maintained by @bayeziddev. Data was originally compiled by nuhil/bangladesh-geocode. The repository includes attribution in its source README.

License

Third-party services

The live map uses Leaflet for rendering and CARTO tiles with OpenStreetMap attribution. The documentation typography is loaded from Google Fonts. These resources are referenced over HTTPS and are not required to browse the data files themselves.

Hosting note: GitHub Pages serves this site as static files. Relative links and local assets remain available even if a third-party map or font request is blocked.
