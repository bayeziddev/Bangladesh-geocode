Credits & Sources

This project packages Bangladesh administrative reference data in formats that are practical for developers, analysts, and GIS users.

Maintainers and sources

Maintained by @bayeziddev. Source information and attribution are documented in the project’s source README. The repository’s data schema describes the included administrative records, relationships, and boundary data.

The published Python distribution is available on PyPI, and the complete source is maintained in the official GitHub repository.
