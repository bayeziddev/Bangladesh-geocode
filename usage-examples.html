Usage Examples

Small, copy-ready examples for the formats most commonly used in web and data projects.

Find a district by name

const districts = await fetch('districts/districts.json').then(r => r.json());
const dhaka = districts.find(item => item.name === 'Dhaka');
console.log(dhaka.lat, dhaka.lon);

Join a parent relation in Python

import json

with open('districts/districts.json') as file:
    districts = json.load(file)
by_division = {item['id']: item for item in districts}
print(by_division[6]['name'])

Load SQL fixtures

mysql your_database < divisions/divisions.sql
mysql your_database < districts/districts.sql
mysql your_database < upazilas/upazilas.sql
mysql your_database < unions/unions.sql
